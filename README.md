# Plataforma --- academica

**Integrante:** Itan Jamyd Vidal Gacha 
**Descripción:** Descripción general
Cada equipo deberá crear un repositorio en GitHub para un proyecto sencillo llamado Plataforma Académica Básica. El proyecto puede contener únicamente archivos iniciales como README.md, index.html, style.css y, opcionalmente, un archivo script.js.
La finalidad no es desarrollar una aplicación completa, sino demostrar el manejo correcto del flujo de trabajo con Git y GitHub.
